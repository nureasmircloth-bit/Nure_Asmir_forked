    Words used in these pages

    Worker
    A small program that runs on Cloudflare’s network, close to the visitor, instead of on one server.
    DNS
    The internet’s phone book. It turns nureasmir.com into the address of a computer.
    Cache
    A saved copy kept nearby so the same answer need not be made again.
    Cold start
    The extra wait when something has been idle and must wake up before answering.
    ISR (saved pages)
    Pages are built once and reused for a short time, then quietly rebuilt.
    Migration
    A numbered database change, applied automatically before each release.
    Canonical address
    The one official address of a page, so Google counts it once.
    Structured data (JSON-LD)
    Hidden facts on a page (price, stock, address) written for machines.
    SEO / GEO
    Being found on Google / being recommended by AI assistants.
    Sandbox
    A safe practice copy where nothing touches real orders or customers.
    PKR
    Pakistani rupees. Every order is charged in PKR; other currencies are only shown as a guide.
    CSP / HSTS
    Browser safety rules the site sends: which scripts may run, and “always use HTTPS”.
