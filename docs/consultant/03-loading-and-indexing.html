A. Problem 1: “This site can’t be reached” for some customers

What was reported: a customer saw ERR_NAME_NOT_RESOLVED on www.nureasmir.com. They were using Google DNS (8.8.8.8 / 8.8.4.4). When they switched to Cloudflare DNS (1.1.1.1) it opened at once.

What we checked: all three names resolve correctly (IPv4 and IPv6) on Google, Cloudflare, Quad9, AdGuard, NextDNS and AliDNS. From 20 countries, 19 loaded the site (one Tehran node timed out, which looks local to that network). DNSSEC is off, so a validation failure is not the cause. The mail and Worker records in Cloudflare are all present. The “CNAME failed” result on dnschecker.org is normal because Cloudflare hides CNAMEs.

Most likely cause (not proven): at one moment that customer’s resolver got no answer for the name (a gap in the records, or a failed lookup to Cloudflare’s servers) and then remembered the empty answer. On the Cloudflare Free plan that memory lasts 30 minutes and cannot be changed. We do not know the exact date and time, so we could not match it to a deploy.

  • Which plan allows editing the SOA record, and is it worth paying for?

D. Admin training sandbox: do we have one?

Today: no real sandbox. The training area (Admin → Training) plays simulated lessons on a pretend screen that looks like the real admin, in Roman Urdu or English, with a written guide. Nothing the learner clicks touches real data, but they also cannot practise freely.

Proposal (not built yet):

  • Guided sandbox: a practice copy of the admin with sample orders and products, a task list (“create a discount code”, “mark an order as shipped”) and automatic checking when the task is done.
  • Open sandbox: the same copy with free hands, like a cloud practice account, reset every night.

How: a third Worker (APP_TARGET=sandbox) connected to a separate Neon database branch filled with sample data; emails, TCS bookings, WhatsApp and push alerts switched off in that mode; a visible “Practice mode” strip; a nightly reset job. We already use a database branch for testing, so the pieces exist. Rough size: a few days; needs a decision on whether practice accounts are shared or per person.

E. Decisions we need from the consultant or owner

  1. Edge-cache the public pages (fix B3), and if yes, with what time.
  2. Smart Placement or a database region closer to Pakistan.
  3. Workers Paid before the first paid advertising.
  4. Whether to pay for DNS controls or a second DNS provider.
  5. Build the practice sandbox (D) before or after launch.
